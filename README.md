# comfyui-hanfu-prompts

14套在 RTX 5070 上跑通的汉服写真提示词，每套都经过双采样验证。

## 为什么做这个

用 ComfyUI + Z-Image Turbo 跑图跑了半个月，发现最难的不是调参数，是想 prompt。

「唐风仕女」写出来简单，但要稳定出图的 prompt 得反复试——红金色比例、光线角度、构图留白，差一个词就可能崩成塑料感。

这里 14 套是我筛过的，每套最少跑了 3 轮验证。

## 包含什么

**汉服写真（5套）**
- 唐风仕女 — 红金、宫殿、灯笼、樱花
- 宋制素雅 — 蓝白、竹林荷塘、薄雾
- 明制端庄 — 深蓝金绣、凤冠、书房烛光
- 魏晋风骨 — 白衣、山崖云雾、仙侠感
- 明艳宫装 — 红金凤冠、故宫大殿、侧光

**王家卫风格（3套）**
- 花样年华 — 红旗袍、雨窗、霓虹
- 重庆森林 — 鱼缸蓝光、凌晨四点
- 堕落天使 — 浴室雾镜、荧光撞色

**杂志封面（4套）**
- VOGUE / 时尚芭莎 / ELLE / COSMO — 顶部留白给排版

**本地图（5套）** — 唐风浴、宋风寝等，仅供本地

## 效果怎么样

说实话不是 100% 成功率。王家卫那三套对环境光线要求高，有时候棉被和旗袍会混成一团。汉服的稳定性最好，唐风那套基本不翻车。杂志封面类留白区域偶尔会被 AI 填上奇怪的东西。

但跑出来的好的图确实能打——放大看头发丝没有塑料感，这是 Z-Image Turbo 比 SDXL 强的地方。

## 使用方法

```bash
pip install comfy-batch
python -m comfy_batch "你的提示词" --double
```

需要 RTX 5070 12GB 或同等算力。Z-Image Turbo 8步采样、双采样模式（先768×1024搭结构 → 放大到1024×1536补细节），一张图约 45 秒。
